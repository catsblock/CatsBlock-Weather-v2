# CatsBlock Weather

CatsBlock Weather is a weather application built with Kotlin and Jetpack Compose.

## Features

- Current weather conditions
- Hourly and daily forecasts
- Weather radar and map layers
- Weather alerts and notifications
- Home-screen weather widgets
- Multiple weather data providers
- Location-based and manually selected cities
- Customizable themes, units, and appearance
- Moon and astronomical information
- Multiple languages

## Platforms

- Android
- Windows desktop

## Built With

- Kotlin
- Jetpack Compose
- Material 3
- Kotlin Coroutines
- AndroidX
- Gradle
